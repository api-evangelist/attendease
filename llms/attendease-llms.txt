# Attendease (EventUp Planner)

> Attendease — now EventUp Planner following its acquisition by Tripleseat — is an event and meeting management platform for planning, promoting, and running virtual, in-person, and hybrid events (conferences, webinars, roadshows, product launches). It publishes a public developer API in two tiers plus first-party JavaScript and Ruby SDKs.

This file was generated by the API Evangelist enrichment pipeline from the public developer documentation and package registries. Method: generated. Source: https://developer.attendease.com/

## APIs

- [Attendease Developer API](https://developer.attendease.com/): Developer portal and reference for both API tiers.
- Organization API (`/api/v2/`): Organization-wide REST API — business units, events, members, attendees, session attendance, check-ins, partners, contact lists. Base URL pattern: https://your-org.attendease.org/api/v2/. Auth: HMAC-SHA1 request signing (`Authorization: APIAuth access_key:signature`, RFC 1123 Date within 15 minutes).
- Event API: Event-scoped REST API — event properties, sessions, session instances, presenters, surveys, sponsors, rooms, venues, filters, content. Base URL pattern: https://your-event.attendease.com/api/. Auth: attendee/event tokens (X-Attendee-Token, X-Event-Token) or HTTP Basic.

## Conventions

- Media type: application/json; resource paths carry a .json suffix.
- Pagination: page-number style; params page + records_per_page (1-100, default 50); pagination envelope with total_records, num_records, page_size, page_count, page.
- Metadata: custom fields filtered via ?meta[key]=value and written in a meta object.
- Errors: custom JSON envelope { "error": "message" }; 422 returns a field-keyed errors object. Not RFC 9457.
- Idempotency: not documented. Rate limits: 429 possible, no published quotas.
